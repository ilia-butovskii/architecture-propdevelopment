Нет описания интерфейсов внешней системы, поэтому взаимодействие сроектировано предполагая, что взаимодействие с внешней системой возможно осуществиить с помощью REST API и механизма Webhook. Настройка вебхука происходит через API, для этого необходимо передать параметры и секретный ключ для подписи сообщений.

API ключ для внешней системы необхоимо хранить в защищенном контейнере
Для запроса к внешнему сервису необходимо передавать API ключ в заголовке. Запросы необходимо осуществялть по HTTPS. Также внешняя система способна отправлять события по устройствам с помощью вебхука. На стороне iot_webhook_service необходимо проверять подпись сообщения ключом, который мы передали при создании вебхука.
Также необходимо добавить механизм бесшовной ротации ключей
